# cc-statusline

Fast, configurable statusline for [Claude Code](https://claude.com/claude-code), written in Rust.

## Status

Early development. Not yet ready for use.

## Goals

- **Fast**: cold start under 5ms (minimal config), under 15ms (full config).
- **Configurable**: TOML config with modules and a starship-like format string.
- **Native modules**: model, context, cost, rate limits, cache hit rate, workspace, git, and more — all built in.
- **Single static binary**, distributed via GitHub Releases.
